## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| readline/promises EOF drop | `readline/promises`'s `question()` silently abandons pending Promises when the readline interface closes due to stdin EOF (piped context). Second question's answer is treated as empty string. | advisory | Use callback-based `createInterface` with a pre-buffered 'line' event queue — see `src/cli/index.ts` `ask()` helper pattern. |
| process.exit() in async Commander handler | Calling `process.exit()` from inside an async Commander action handler produces exit code 13 ("Unfinished Top-Level Await") and drops buffered stderr writes. | advisory | Use `writeSync(fd, msg)` + `process.exitCode = N` + `process.stdin.destroy()` + `return` instead of `process.exit()`. |
| npm link from worktree | `npm link` run inside an isolated git worktree points the global symlink to the worktree path; when the worktree is removed the symlink becomes dangling. | advisory | Always re-run `npm link` from the main checkout after worktrees are cleaned up. |
