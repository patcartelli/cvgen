<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| resume markdown file → Claude API extraction → ResumeData | User-authored markdown crosses into the extraction layer (pre-existing boundary; unchanged by this phase) |
| ResumeData → designedHtmlTemplate() → HTML string → Puppeteer | Structured data is interpolated into the HTML template body; every interpolation point goes through `escapeHtml()` (pre-existing boundary; unchanged by this phase) |
| Static CSS literals in the `<style>` block | No trust boundary — all values (`#2d4a6b`, `4px`, `12px`, `0`, `var(--bullet)`) are hardcoded developer-authored constants; no user input reaches the `<style>` block |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | CSS values in the `<style>` block of `designedHtmlTemplate()` | mitigate | All new CSS values (`#2d4a6b`, `4px`, `12px`, `0`, `var(--bullet)`) are hardcoded string literals in the TypeScript template — no template interpolation is added inside `<style>`. Task 1 acceptance criteria explicitly forbid touching `escapeHtml` or any HTML interpolation point. |
| T-05-02 | Tampering | HTML template interpolation points outside `<style>` | accept | Pre-existing `escapeHtml()` guard on all `data.*` interpolation points (lines 32-39 of render.ts) is unchanged by this phase. No new interpolation points are added anywhere in the template. Existing coverage is sufficient (ASVS V5 not triggered — no new input surface). |
| T-05-03 | Information Disclosure | designedHtmlTemplate rendering | accept | No sensitive data is added, removed, or reordered in the output PDF. Layout only. |
| T-05-04 | Denial of Service | Puppeteer PDF render | accept | New CSS rules add no computation cost (three property changes, two trivial rules — `li::marker` and adjacent sibling). Chromium's layout engine handles these in O(n) over already-rendered elements. |
| T-05-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed in this phase (RESEARCH.md § "Package Legitimacy Audit" is intentionally empty; no `npm install`/`pip install`/`cargo add` in Task 1). Legitimacy gate not triggered. |
