## Design Decisions Made This Session

All changes are in `src/lib/render.ts` — the `designedHtmlTemplate()` function only. The ATS template is unchanged.

### Color Tokens
```css
--accent: #FEAC03   /* amber — used ONCE: 1px border-bottom on contact block */
--text:   #232323   /* Font Main */
--muted:  #555555   /* Font Subtle */
--border: #e0e0e0
```

### Typescale (all font-weight: 400 — Regular everywhere)
| Token       | Size | Line-height | Color  | Used on                          |
|-------------|------|-------------|--------|----------------------------------|
| Title       | 20px | 30px        | --text | Candidate name                   |
| body/main   | 14px | 21px        | --text | Role title, summary, skills      |
| body/small  | 12px | 21px        | --muted| Contact, dates, type badge, chip |
| body/list   | 12px | 18px        | --muted| Bullet list items                |
| body/heading| 14px | 21px        | --text | Section headers (same as main)   |

**No bold anywhere in the designed PDF.** Hierarchy comes from size + color only.

### Layout
- **Two-column grid** per entry: `grid-template-columns: 150px 1fr; gap: 0 1.5em`
  - Left: date (body/small, muted, `white-space: nowrap`)
  - Right: "Company — Role (type)" + bullets
- Experience entry format: `Company — Role (Contract)` using em dash
- Date range format: `startDate – endDate` using en dash

### Spacing System
```
Contact block bottom → first section heading : 48px  (margin-top on .section-header)
Section heading → summary paragraph          :  4px  (margin-top on section > p)
Section heading → first experience entry     : 24px  (margin-top on .experience-entry)
Between experience entries                   : 24px  (margin-top collapses to 24px)
```

### Contact Line
Plain text, single line, muted color, `|` separator:
```
email | phone | location | linkedin | github
```
No chips. All 5 fields always rendered.

### Section Headers
No uppercase, no letter-spacing, no border-bottom. Plain body/heading (14/21 Regular, Font Main) with 48px margin-top.

### Accent Usage
Accent (#FEAC03) appears **only** as the 1px `border-bottom` on the contact block. Nowhere else.
