Puppeteer usage pattern (from RESEARCH.md Pattern 1 / 2):
- `browser.newPage()` -> new Page (caller passes shared Browser)
- Designed: `page.setContent(html, { waitUntil: "networkidle0" })` then `await page.waitForNetworkIdle()` then `page.pdf({...})`
- ATS: `page.setContent(html, { waitUntil: "load" })` then `page.pdf({...})`
- Always `page.close()` in a finally block; never `browser.close()` inside the render function.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Resume string fields → HTML template | Untrusted-shape strings (candidate-authored bullets, company names) interpolated into HTML; a `<` or `&` in a bullet would corrupt the DOM and the resulting PDF text |
| Puppeteer → Google Fonts CDN (fonts.googleapis.com + fonts.gstatic.com) | Outbound network call from headless Chrome during render; failure/tamper affects designed PDF only |
| npm registry → local machine | New dependencies (puppeteer, pdf-parse) execute install-time code; puppeteer downloads a Chromium binary via postinstall |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | HTML template interpolation in designedHtmlTemplate / atsHtmlTemplate | mitigate | Route every string value from `ResumeData` through the module-local `escapeHtml()` helper (5 replacements, `&` first) before interpolation; enforced via grep-gate on presence of escapeHtml and absence of raw `${data...}` in tag positions |
| T-03-02 | Information Disclosure | Google Fonts CDN fetch | accept | Loading Inter from fonts.googleapis.com is the locked D-D02 decision; the only data leaked is the CSS URL itself (no resume data). Acceptable for a personal CLI. Fallback (self-hosted Inter) deferred to v2. |
| T-03-03 | Denial of Service | Puppeteer launch failing on Chromium missing | mitigate | Use full `puppeteer` package (not puppeteer-core) per CLAUDE.md — postinstall downloads a matched Chromium; smoke test in Task 3 fails loudly if Chromium is missing |
| T-03-SC | Tampering | npm install of `puppeteer` + `pdf-parse` | accept | Both packages are `[ASSUMED]` per RESEARCH.md Package Legitimacy Audit and gate open on age (13yr / 8yr) + weekly download volume (11.4M / 6.7M) + widely-documented behavior; slopcheck was unavailable at research time. No blocking human checkpoint required for these two well-known packages. |
</threat_model>
